# Seaforged GitHub Organization Profile

## What This Is

The GitHub organization profile repo for Seaforged. `profile/README.md` renders as the landing page at github.com/Seaforged.

## Non-Negotiables

- Always use the `seaforged-brand` skill when touching `profile/README.md` — enforces brand colors, typography, logo placement
- Product descriptions must be concise (1-2 sentences each)
- Keep the logo and badges at the top of the README
- Update product status fields when underlying repos change
- Never remove the veteran-owned / NDAA-compliant / FAA Part 107 / Made in USA identity lines

## Commands

No build system. Edit `profile/README.md`, commit, push — GitHub renders immediately.
