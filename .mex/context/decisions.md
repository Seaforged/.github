# Decisions

## Decision Log

### Brand identity lines on every visible surface
**Date:** 2025
**Status:** Active
**Decision:** The four identity lines (Veteran-Owned / NDAA / FAA Part 107 / Made in USA) appear on the org profile README and on every product README.
**Reasoning:** These are customer-facing differentiators for the defense / government market. Removing them from even one place weakens the pattern.
**Consequences:** All six product repos must maintain these lines. Changes to the phrasing ripple across the org.
